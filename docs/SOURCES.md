# Sources for the history lesson

Every factual claim the tutor makes (and the animated scenes show) in the "Where the cube came from" lesson, with where it was checked.

| Claim in the narration | Source |
| --- | --- |
| Ernő Rubik built the first working prototype in 1974 in Budapest, while teaching design; it took him about a month to solve it | [Ernő Rubik (Wikipedia)](https://en.wikipedia.org/wiki/Ern%C5%91_Rubik), [Mental Floss: How Ernő Rubik created the cube](https://www.mentalfloss.com/article/58162/how-erno-rubik-created-rubiks-cube) |
| Sold as the "Magic Cube" in Budapest toy shops from 1977; renamed Rubik's Cube for the 1980 worldwide launch | [Ernő Rubik (Wikipedia)](https://en.wikipedia.org/wiki/Ern%C5%91_Rubik), [Telex: Half a century of the Rubik's Cube](https://telex.hu/english/2024/06/20/half-a-century-of-the-rubiks-cube-first-a-mainstream-game-then-a-pop-culture-icon) |
| 43,252,003,274,489,856,000 possible positions ("more than forty-three quintillion") | [cube20.org](https://cube20.org/) |
| One position per second ≈ 100 × the age of the universe (≈ 1.4 trillion years, shown in the scene) | Arithmetic: 4.3 × 10¹⁹ s ÷ 3.156 × 10⁷ s/year ≈ 1.37 × 10¹² years; ÷ 13.8 × 10⁹ years ≈ 99 |
| First world championship: Budapest, 1982, won in 22.95 seconds (Minh Thai) | [1982 World Rubik's Cube Championship (Wikipedia)](https://en.wikipedia.org/wiki/1982_World_Rubik%27s_Cube_Championship), [WCA: WC1982](https://www.worldcubeassociation.org/competitions/WC1982) |
| 2010: proven that every position can be solved in 20 moves or fewer ("God's number") | [cube20.org](https://cube20.org/), [Phys.org (2010)](https://phys.org/news/2010-08-uncovers-rubik-cube-solution.html) |

Algorithm claims are not listed here: each one is proven by `src/engine/algorithms.test.ts`.
